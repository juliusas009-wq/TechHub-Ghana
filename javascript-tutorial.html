Java Programming Tutorial

Learn Java programming from beginner to practical level with simple explanations, examples, exercises and projects.

1. What is Java?

Java is a high-level, object-oriented programming language used to build many different types of software applications.

Java is widely used for:

  • Desktop applications
  • Web applications
  • Enterprise software
  • Backend systems
  • Android development
  • Cloud applications
  • Large business systems

One of Java's major advantages is its platform independence.

2. Why Learn Java?

Java remains an important programming language because it is used in many real-world software systems.

  • Object-oriented programming
  • Platform independent
  • Strongly typed
  • Large developer community
  • Widely used in enterprise applications
  • Useful for backend development
  • Excellent for learning programming concepts

3. Your First Java Program

The following program displays Hello World! on the screen. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

The output will be: 

Hello World!

The System.out.println() statement is used to display information in the console.

4. Java Variables

A variable is a named storage location used to hold information in a program. 

String name = "Julius";

int age = 20;

double price = 25.50;

boolean student = true;

In this example:

  • name stores text.
  • age stores an integer.
  • price stores a decimal number.
  • student stores true or false.

7. If Statement

An if statement allows a program to make decisions. 

int age = 20;

if (age >= 18) {

    System.out.println("You are an adult.");

}

if / else 

int age = 16;

if (age >= 18) {

    System.out.println("Adult");

} else {

    System.out.println("Minor");

}

if / else if / else 

int score = 75;

if (score >= 80) {

    System.out.println("A");

} else if (score >= 70) {

    System.out.println("B");

    System.out.println("C");

8. Switch Statement

A switch statement can be used when you want to compare a value against several possible cases. 

int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");

}

9. For Loop

A for loop is used to repeat a block of code a specific number of times. 

for (int i = 1; i <= 5; i++) {

    System.out.println(i);

}

Output: 

1
2
3
4
5

10. While Loop

A while loop continues running while a condition remains true. 

int number = 1;

while (number <= 5) {

    System.out.println(number);

    number++;

}

11. Arrays

An array stores multiple values of the same data type. 

String[] students = {
    "Julius",
    "Ama",
    "Kofi"
};

System.out.println(students[0]);

Java array indexes start from 0. 

students[0]  // Julius

students[1]  // Ama

students[2]  // Kofi

12. Methods

A method is a reusable block of code designed to perform a particular task. 

public static void greet() {

    System.out.println("Welcome to TechHub Ghana");

}


public static void main(String[] args) {

    greet();

}

Method with Parameters 

public static void greet(String name) {

    System.out.println("Hello " + name);

}


public static void main(String[] args) {

    greet("Julius");

}

13. Classes and Objects

Java is an object-oriented programming language. A class is a blueprint for creating objects. 

class Student {

    String name;

    int age;

}


public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "Julius";

        student.age = 20;

        System.out.println(student.name);

        System.out.println(student.age);

    }

}

14. Constructors

A constructor is a special method that is called when an object is created. 

class Student {

    String name;

    int age;


    Student(String name, int age) {

        this.name = name;

        this.age = age;

    }

}


public class Main {

    public static void main(String[] args) {

        Student student =
            new Student("Julius", 20);

        System.out.println(student.name);

        System.out.println(student.age);

    }

}

15. Inheritance

Inheritance allows one class to inherit properties and methods from another class. 

class Animal {

    void sound() {

        System.out.println("Animal makes a sound");

    }

}


class Dog extends Animal {

    void bark() {

        System.out.println("Dog barks");

    }

}


public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();

        dog.bark();

    }

}

16. Encapsulation

Encapsulation means keeping data protected inside a class and controlling access to it through methods. 

class Student {

    private String name;


    public void setName(String name) {

        this.name = name;

    }


    public String getName() {

        return name;

    }

}


public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.setName("Julius");

        System.out.println(student.getName());

    }

}

17. Exception Handling

Exception handling allows a program to handle unexpected errors without immediately stopping. 

try {

    int number = 10 / 0;

} catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero.");

}

18. User Input

Java can receive input from a user using the Scanner class. 

import java.util.Scanner;


public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");

        String name = input.nextLine();

        System.out.println("Hello " + name);

    }

}

19. Practical Student Grading Program

Let's combine variables, input, conditions and output to create a simple student grading program. 

import java.util.Scanner;


public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);


        System.out.print("Enter student name: ");

        String name = input.nextLine();


        System.out.print("Enter score: ");

        int score = input.nextInt();


        String grade;


        if (score >= 80) {

            grade = "A";

        } else if (score >= 70) {

            grade = "B";

        } else if (score >= 60) {

            grade = "C";

        } else if (score >= 50) {

            grade = "D";

        } else {

            grade = "F";

        }


        System.out.println();

        System.out.println("Student: " + name);

        System.out.println("Score: " + score);

        System.out.println("Grade: " + grade);

    }

}

20. Complete Practical Example

The following program combines several Java concepts into a simple student information system. 

import java.util.Scanner;


public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);


        System.out.print("Enter student name: ");

        String name = input.nextLine();


        System.out.print("Enter age: ");

        int age = input.nextInt();


        System.out.print("Enter GPA: ");

        double gpa = input.nextDouble();


        System.out.println();

        System.out.println("----- STUDENT INFORMATION -----");

        System.out.println("Name: " + name);

        System.out.println("Age: " + age);

        System.out.println("GPA: " + gpa);

    }

}
