Java Programming Tutorial

Learn Java step-by-step from beginner level to practical programming.

1. Introduction to Java

Java is a popular programming language used to build desktop applications, mobile applications, web applications and enterprise software.

Why Learn Java?

  • Easy to learn
  • Object-oriented
  • Platform independent
  • Widely used in software development
  • Useful for Android and backend development

2. Your First Java Program

A simple Java program looks like this: 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

The program prints: 

Hello World!

3. Variables

Variables are used to store information. 

String name = "Julius";

int age = 20;

double price = 25.50;

boolean student = true;

4. Data Types

Common Java data types include:

  • int
  • double
  • float
  • char
  • boolean
  • String
int number = 10;

5. If Statement

An if statement allows Java to make decisions. 

int age = 20;

if (age >= 18) {

    System.out.println("You are an adult.");

}

6. Loops

Loops allow you to repeat instructions. 

for (int i = 1; i <= 5; i++) {

    System.out.println(i);

}

Output:

1
2
3
4
5

7. Methods

Methods are blocks of code designed to perform a specific task. 

public static void greet() {

    System.out.println("Welcome to TechHub Ghana");

}

public static void main(String[] args) {

    greet();

}

8. Classes and Objects

Java is an object-oriented programming language. Classes are used to create objects. 

class Student {

    String name;

    int age;

}

public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "Julius";

        student.age = 20;

        System.out.println(student.name);

    }

}

🎯 Java Quiz

1. Which keyword is used to create a class?

A. object

B. class

C. create

D. new

Answer: B. class

2. Which method starts a Java program?

A. start()

B. run()

C. main()

D. execute()

Answer: C. main()
