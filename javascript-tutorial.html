Java Programming Tutorial

Learn Java step-by-step from beginner level to practical programming, object-oriented programming and real-world projects.

1. Introduction to Java

Java is a high-level, general-purpose programming language widely used to build desktop applications, web applications, enterprise software and other software systems.

Java follows the object-oriented programming approach, which allows developers to organize programs using classes and objects.

Why Learn Java?

  • Easy to learn and widely documented.
  • Object-oriented.
  • Platform independent through the Java Virtual Machine.
  • Widely used in software development.
  • Useful for backend development.
  • Supports large-scale enterprise applications.

2. Your First Java Program

A simple Java program that displays "Hello World!" looks like this: 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

The program produces: 

Hello World!

System.out.println() is used to display information in the console.

3. Variables

Variables are used to store information that a program can use. 

String name = "Julius";

int age = 20;

double price = 25.50;

boolean student = true;

In this example:

  • name stores text.
  • age stores an integer.
  • price stores a decimal number.
  • student stores a true/false value.

4. Java Data Types

Java provides several data types for storing different kinds of information.

Common Primitive Data Types

  • int — whole numbers.
  • double — decimal numbers.
  • float — decimal numbers with lower precision than double.
  • char — a single character.
  • boolean — true or false.
  • long — large whole numbers.

Example 

int number = 10;

double salary = 2500.50;

float temperature = 25.5f;

char grade = 'A';

boolean passed = true;

long population = 30000000L;

String name = "Julius";

5. Java Operators

Operators are symbols used to perform operations on values and variables.

Arithmetic Operators 

int a = 10;

int b = 3;

System.out.println(a + b);

System.out.println(a - b);

System.out.println(a * b);

System.out.println(a / b);

System.out.println(a % b);

Common arithmetic operators include:

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus

6. If Statements

An if statement allows a Java program to make decisions. 

int age = 20;

if (age >= 18) {

    System.out.println("You are an adult.");

}

if / else 

int age = 16;

if (age >= 18) {

    System.out.println("Adult");

} else {

    System.out.println("Minor");

}

if / else if / else 

int score = 75;

if (score >= 80) {

    System.out.println("Grade A");

} else if (score >= 70) {

    System.out.println("Grade B");

} else if (score >= 60) {

    System.out.println("Grade C");

} else {

    System.out.println("Fail");

}

7. Switch Statement

A switch statement can be used when you need to compare one value against several possible cases. 

int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");

}

8. Loops

Loops allow you to execute a block of code repeatedly.

For Loop 

for (int i = 1; i <= 5; i++) {

    System.out.println(i);

}

Output: 

1
2
3
4
5

While Loop 

int number = 1;

while (number <= 5) {

    System.out.println(number);

    number++;

}

Do-While Loop 

int number = 1;

do {

    System.out.println(number);

    number++;

} while (number <= 5);

9. Arrays

An array stores multiple values of the same data type. 

int[] numbers = {
    10,
    20,
    30,
    40,
    50
};

System.out.println(numbers[0]);

Java array indexes begin at 0.

Loop Through an Array 

int[] numbers = {
    10,
    20,
    30,
    40,
    50
};

for (int number : numbers) {

    System.out.println(number);

}

10. Methods

A method is a reusable block of code designed to perform a particular task. 

public static void greet() {

    System.out.println("Welcome to TechHub Ghana");

}

public static void main(String[] args) {

    greet();

}

Method with Parameters 

public static void greet(String name) {

    System.out.println("Hello " + name);

}

public static void main(String[] args) {

    greet("Julius");

}

Method with a Return Value 

public static int add(int a, int b) {

    return a + b;

}

public static void main(String[] args) {

    int result = add(10, 20);

    System.out.println(result);

}

11. Classes and Objects

Java is an object-oriented programming language. A class is a blueprint for creating objects. 

class Student {

    String name;

    int age;

}

public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "Julius";

        student.age = 20;

        System.out.println(student.name);

        System.out.println(student.age);

    }

}

In this example, Student is a class and student is an object created from that class.

12. Constructors

A constructor is a special method used to initialize an object when it is created. 

class Student {

    String name;

    int age;


    Student(String name, int age) {

        this.name = name;

        this.age = age;

    }

}

public class Main {

    public static void main(String[] args) {

        Student student =
            new Student("Julius", 20);

        System.out.println(student.name);

        System.out.println(student.age);

    }

}

13. Encapsulation

Encapsulation means keeping data and the methods that operate on that data together while controlling how the data is accessed. 

class Student {

    private String name;


    public void setName(String name) {

        this.name = name;

    }


    public String getName() {

        return name;

    }

}

public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.setName("Julius");

        System.out.println(student.getName());

    }

}

14. Inheritance

Inheritance allows one class to inherit properties and methods from another class. 

class Animal {

    void sound() {

        System.out.println("Animal makes a sound");

    }

}


class Dog extends Animal {

    void bark() {

        System.out.println("Dog barks");

    }

}


public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();

        dog.bark();

    }

}

15. Polymorphism

Polymorphism allows objects to behave differently depending on the class or method implementation. 

class Animal {

    void sound() {

        System.out.println("Animal sound");

    }

}


class Dog extends Animal {

    @Override
    void sound() {

        System.out.println("Dog barks");

    }

}


public class Main {

    public static void main(String[] args) {

        Animal animal = new Dog();

        animal.sound();

    }

}

16. User Input

Java provides the Scanner class for reading input from the keyboard. 

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.print("Enter your name: ");

        String name = input.nextLine();

        System.out.println("Hello " + name);

        input.close();

    }

}

Reading Numbers 

import java.util.Scanner;

17. Working with Strings

Strings are used to store text. 

String name = "Julius";

System.out.println(name.length());

System.out.println(name.toUpperCase());

System.out.println(name.toLowerCase());

System.out.println(name.charAt(0));

Useful String methods include:

  • length() — returns the number of characters.
  • toUpperCase() — converts text to uppercase.
  • toLowerCase() — converts text to lowercase.
  • charAt() — returns a character at a specific index.

18. Exception Handling

Exception handling allows a program to respond to unexpected errors without immediately crashing. 

try {

    int result = 10 / 0;

    System.out.println(result);

} catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero.");

}

🎯 21. Mini Java Project

Let's create a simple student grading system.

The program will:

  • Ask for the student's name.
  • Ask for the student's score.
  • Determine the grade.
  • Display the student's name and grade.

Example Solution 

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);


        System.out.print("Enter student name: ");

        String name = input.nextLine();


        System.out.print("Enter score: ");

        int score = input.nextInt();


        String grade;


        if (score >= 80) {

            grade = "A";

        } else if (score >= 70) {

            grade = "B";

        } else if (score >= 60) {

            grade = "C";

        } else if (score >= 50) {

            grade = "D";

        } else {

            grade = "F";

        }


        System.out.println();

        System.out.println("Student: " + name);

        System.out.println("Score: " + score);

        System.out.println("Grade: " + grade);


        input.close();

    }

}
