CSS Tutorial for Beginners

Learn how to design beautiful, responsive and modern websites using Cascading Style Sheets (CSS).

1. What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML websites.

HTML creates the structure of a website, while CSS makes that website beautiful and easier to use. 

h1 {
    color: blue;
}

The code above changes the color of an HTML heading to blue.

2. How to Add CSS to HTML

There are three main ways to add CSS to a webpage:

  • Inline CSS
  • Internal CSS
  • External CSS

Inline CSS 

<h1 style="color: blue;">
    Hello World
</h1>

Internal CSS 

<style>

h1 {
    color: blue;
}

</style>

External CSS 

<link rel="stylesheet" href="style.css">

External CSS is commonly used for professional websites because one CSS file can control many HTML pages.

3. CSS Selectors

Selectors tell CSS which HTML element should be styled.

Element Selector 

p {
    color: green;
}

Class Selector 

.card {
    background: white;
}

ID Selector 

#header {
    background: black;
}

4. CSS Colors

CSS allows you to change text, background and border colors. 

h1 {
    color: red;
}

body {
    background-color: #f5f5f5;
}

5. CSS Fonts 

body {
    font-family: Arial, sans-serif;
}

h1 {
    font-size: 40px;
}

6. CSS Box Model

Every HTML element can be thought of as a box. The CSS box model contains:

  • Content
  • Padding
  • Border
  • Margin 
.card {
    padding: 20px;
    margin: 20px;
    border: 1px solid #ccc;
}

7. CSS Flexbox

Flexbox is useful for arranging elements horizontally or vertically. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

8. CSS Grid

CSS Grid is useful for creating layouts with rows and columns. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

9. Responsive Design

Responsive design makes websites work properly on phones, tablets and computers. 

@media (max-width: 768px) {

    .container {
        grid-template-columns: 1fr;
    }

}

10. CSS Hover Effects

The :hover selector allows you to change an element when the user moves the mouse over it. 

button {
    background: blue;
    color: white;
    padding: 10px 20px;
}

button:hover {
    background: black;
}

11. Practical CSS Project

Let's create a simple technology card. 

<div class="card">

    <h2>TechHub Ghana</h2>

    <p>
        Learn technology online.
    </p>

    <button>
        Learn More
    </button>

</div>

CSS: 

.card {
    width: 300px;
    padding: 20px;
    background: white;
    border-radius: 10px;
    box-shadow: 0 4px 15px rgba(0,0,0,0.1);
}

.card h2 {
    color: #007bff;
}

.card button {
    background: #007bff;
    color: white;
    border: none;
    padding: 10px 20px;
    border-radius: 5px;
    cursor: pointer;
}

  3. A blue button called "Learn More"
  4. A card with padding and a border
  5. A responsive layout
