Lesson 1: Introduction to Java

Java is a popular programming language used to build desktop applications, mobile applications, web applications and enterprise software.

Why Learn Java?

  • Easy to learn
  • Object-oriented
  • Platform independent
  • Widely used in software development
  • Useful for Android and backend development

Lesson 2: Your First Java Program

A simple Java program looks like this: 


public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

The program prints: 


Hello World!

Lesson 7: Methods

Methods are blocks of code designed to perform a specific task.

    System.out.println("Welcome to TechHub Ghana");

public static void main(String[] args) {

    greet();

}

Lesson 8: Classes and Objects

Java is an object-oriented programming language. Classes are used to create objects. 


class Student {

    String name;

    int age;

}

public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "Julius";

        student.age = 20;

        System.out.println(student.name);

    }

}

🎯 Java Quiz

1. Which keyword is used to create a class?

A. object

B. class

C. create

D. new

Answer: B. class

2. Which method starts a Java program?

A. start()

B. run()

C. main()

D. execute()

Answer: C. main()
