🌐 HTML for Beginners

Welcome to the TechHub Ghana HTML Tutorial. This course teaches you how to build the structure of websites using HTML, starting from the basics and moving toward practical website development.

1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

HTML tells the browser what different parts of a webpage are, such as headings, paragraphs, images, links, tables and forms.

💡 Remember:

HTML provides the structure of a website. CSS provides the design. JavaScript provides interaction.

2. Basic HTML Structure

Every normal HTML page starts with a basic document structure. 

<!DOCTYPE html>

<html lang="en">

<head>

    <title>My Website</title>

</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

The important parts are:

  • <!DOCTYPE html> tells the browser that the document uses HTML5.
  • <html> is the root element.
  • <head> contains information about the webpage.
  • <title> defines the browser tab title.
  • <body> contains the visible webpage content.

3. HTML Headings

HTML provides six levels of headings. 

<h1>Main Heading</h1>

<h2>Second Heading</h2>

<h3>Third Heading</h3>

<h4>Fourth Heading</h4>

<h5>Fifth Heading</h5>

<h6>Sixth Heading</h6>

<h1> represents the highest-level heading, while <h6> represents the lowest-level heading.

4. Paragraphs

The <p> element is used to create paragraphs. 

<p>
Welcome to TechHub Ghana.
</p>

<p>
Learn programming and technology with us.
</p>

5. HTML Links

Links allow users to move from one webpage to another. 

<a href="https://example.com">
    Visit Website
</a>

The href attribute specifies where the link goes.

Link to another page 

<a href="about.html">
    About Us
</a>

6. HTML Images

The <img> element displays an image. 

<img
    src="images/logo.png"
    alt="TechHub Ghana Logo"
>

The src attribute specifies the image location. The alt attribute provides alternative text.

7. HTML Lists

Unordered List 

<ul>

    <li>Python</li>

    <li>JavaScript</li>

    <li>HTML</li>

</ul>

Ordered List 

<ol>

    <li>Learn HTML</li>

    <li>Learn CSS</li>

    <li>Learn JavaScript</li>

</ol>

8. HTML Tables

Tables are useful for displaying information in rows and columns. 

<table>

    <tr>

        <th>Name</th>

        <th>Age</th>

        <th>Course</th>

    </tr>

    <tr>

        <td>Julius</td>

        <td>20</td>

        <td>Information Technology</td>

    </tr>

</table>
  • <table> creates the table.
  • <tr> creates a row.
  • <th> creates a table heading cell.
  • <td> creates a table data cell.

9. HTML Forms

Forms allow websites to collect information from users. 

<form>

    <label for="name">
        Name
    </label>

    <input
        id="name"
        type="text"
        placeholder="Enter your name"
    >

    <br><br>

    <label for="email">
        Email
    </label>

    <input
        id="email"
        type="email"
        placeholder="Enter your email"
    >

    <br><br>

    <button type="submit">
        Submit
    </button>

</form>

Common input types

  • text
  • email
  • password
  • number
  • date
  • file
  • checkbox
  • radio

10. Semantic HTML

Semantic elements describe the meaning of different sections of a webpage. 

<header>
    Website Header
</header>

<nav>
    Navigation Links
</nav>

<main>
    Main Content
</main>

<section>
    Section Content
</section>

<footer>
    Website Footer
</footer>

Semantic HTML improves website structure, accessibility and search-engine understanding.

11. HTML Attributes

Attributes provide additional information about HTML elements. 

<a
    href="about.html"
    class="read-btn"
>
    Read More
</a>

Common attributes include:

  • id
  • class
  • href
  • src
  • alt
  • title
  • style

12. HTML Comments

Comments are notes written inside HTML code that are not displayed as webpage content. 

<!-- This is an HTML comment -->

16. HTML Mini Project

Create a simple personal profile webpage. Your page should contain:

  • A page title
  • Your name
  • Your profile image
  • A short biography
  • Your skills
  • Your education
  • Your hobbies
  • A contact form

Example Project Structure 

<!DOCTYPE html>

<html lang="en">

<head>

    <title>
        My Profile
    </title>

</head>

<body>

    <header>

        <h1>
            My Personal Profile
        </h1>

    </header>

    <main>

        <img
            src="profile.jpg"
            alt="My Profile Photo"
            width="200"
        >

        <h2>
            About Me
        </h2>

        <p>

            My name is Julius.
            I am an Information Technology student.

        </p>

        <h2>
            My Skills
        </h2>

        <ul>

            <li>HTML</li>
            <li>Python</li>
            <li>SQL</li>
            <li>JavaScript</li>

        </ul>

    </main>

    <footer>

        <p>
            © 2026 My Profile
        </p>

    </footer>

</body>

</html>

Build the profile page yourself without copying the example. Try adding your own design, navigation, links and sections.
