1. What is Python?

Python is a high-level programming language used to create software, websites, automation tools, artificial intelligence systems, data analysis applications and many other technologies.

Python is popular because its syntax is relatively simple and easy to read.

🐍 What Can Python Be Used For?

  • Web development
  • Artificial Intelligence
  • Machine Learning
  • Data Science
  • Automation
  • Cybersecurity
  • Software development

print("Hello World!")

The print() function displays information on the screen.

3. Variables

A variable is a name used to store data. 

name = "Julius"

age = 20

country = "Ghana"

print(name)
print(age)
print(country)

In this example:

  • name stores text.
  • age stores a number.
  • country stores text.

4. Python Data Types

Python has several important data types.

  • String
  • Integer
  • Float
  • Complex
  • List
  • Tuple
  • Set
  • Dictionary
  • Boolean
name = "Julius"          # String

age = 20                 # Integer

price = 25.50            # Float

numbers = [1, 2, 3]      # List

items = (1, 2, 3)        # Tuple

unique = {1, 2, 3}       # Set

student = {
    "name": "Julius",
    "age": 20
}                        # Dictionary

passed = True             # Boolean

5. Strings

A string is text surrounded by quotation marks. 

name = "Julius"

print(name)

print(name.upper())

print(name.lower())

print(len(name))

Useful string methods include:

  • upper() — converts text to uppercase.
  • lower() — converts text to lowercase.
  • len() — returns the number of characters.

6. Lists

A list stores multiple values in one variable. 

students = [
    "Julius",
    "Ama",
    "Kofi"
]

print(students)

print(students[0])

Python list indexes start from 0. 

students[0]  # Julius

students[1]  # Ama

students[2]  # Kofi

7. Tuples

A tuple is similar to a list, but tuples are immutable, meaning their elements cannot normally be changed after creation. 

coordinates = (10, 20)

print(coordinates)

print(coordinates[0])

8. Sets

A set is a collection that stores unique values. 

numbers = {1, 2, 3, 3, 4}

print(numbers)

Duplicate values are automatically removed.

9. Dictionaries

A dictionary stores information using key-value pairs. 

student = {

    "name": "Julius",

    "age": 20,

    "course": "Information Technology"

}

print(student["name"])

print(student["course"])

10. Conditions

Conditions allow a program to make decisions. 

age = 20

if age >= 18:

    print("Adult")

else:

    print("Minor")

if / elif / else 

score = 75

if score >= 80:

    print("A")

elif score >= 70:

    print("B")

elif score >= 60:

    print("C")

else:

    print("Fail")

11. Loops

Loops allow you to repeat instructions.

For Loop 

for number in range(1, 6):

    print(number)

Output: 

1
2
3
4
5

While Loop 

number = 1

while number <= 5:

    print(number)

    number += 1

12. Functions

A function is a reusable block of code designed to perform a particular task. 

def greet():

    print("Welcome to TechHub Ghana")


greet()

Function with Parameters 

def greet(name):

    print(f"Hello {name}")


greet("Julius")

13. f-Strings

f-strings make it easy to insert variables inside text. 

name = "Julius"

age = 20

print(f"My name is {name} and I am {age} years old.")

Output: 

My name is Julius and I am 20 years old.

14. User Input

The input() function allows a Python program to receive information from a user. 

name = input("Enter your name: ")

print(f"Hello {name}")

Getting Numbers

Input received from input() is normally returned as text, so it may need to be converted when performing numerical calculations. 

age = int(input("Enter your age: "))

print(age)

🎯 17. Mini Python Project

Create a simple student grading system.

The program should:

  • Ask for the student's name.
  • Ask for the student's score.
  • Determine the grade.
  • Display the student's name and grade.

Example Solution 

name = input("Enter student name: ")

score = int(input("Enter score: "))


if score >= 80:

    grade = "A"

elif score >= 70:

    grade = "B"

elif score >= 60:

    grade = "C"

elif score >= 50:

    grade = "D"

else:

    grade = "F"


print(f"{name} received grade {grade}")

🚀 Challenge

Improve the grading system by adding:

  • Student ID
  • Course name
  • Multiple subjects
  • Total score
  • Average score
  • Grade calculation

Try to build the program yourself before looking for a solution.
