MySQL Database Tutorial

Learn how to create databases, tables, insert data, write SQL queries and manage databases using MySQL.

1. What is MySQL?

MySQL is a relational database management system used to store, organize and retrieve data.

For example, a school can use MySQL to store:

  • Students
  • Courses
  • Lecturers
  • Grades
  • Fees

2. What is a Database?

A database is an organized collection of information.

For example: 

SchoolDB
│
├── Students
├── Courses
├── Lecturers
└── Results

3. Create a Database

The CREATE DATABASE command creates a new database. 

CREATE DATABASE SchoolDB;

To use the database: 

USE SchoolDB;

4. Create a Table

A table stores information in rows and columns. 

CREATE TABLE Students (

    student_id INT PRIMARY KEY,

    name VARCHAR(100),

    age INT,

    course VARCHAR(100)

);

5. Insert Data

Use INSERT INTO to add information to a table. 

INSERT INTO Students
(student_id, name, age, course)

VALUES

(1, 'Kwame Mensah', 21, 'Information Technology');

You can insert multiple students: 

INSERT INTO Students
(student_id, name, age, course)

VALUES

(2, 'Ama Boateng', 20, 'Computer Science'),

(3, 'Kofi Asante', 22, 'Information Technology'),

(4, 'Akua Mensah', 21, 'Cybersecurity');

6. Display Data

Use SELECT to retrieve information. 

SELECT * FROM Students;

The asterisk (*) means all columns.

7. Select Specific Columns 

SELECT name, course
FROM Students;

8. WHERE Clause

The WHERE clause allows you to find specific records. 

SELECT *
FROM Students
WHERE course = 'Information Technology';

9. UPDATE Data

Use UPDATE to change existing information. 

UPDATE Students

SET age = 22

WHERE student_id = 1;

⚠️ Always use a WHERE condition when updating specific records.

10. DELETE Data

Use DELETE to remove a record. 

DELETE FROM Students

WHERE student_id = 4;

⚠️ Be careful with DELETE. Without a WHERE condition, you could delete every record in the table.

11. ORDER BY

ORDER BY sorts your results. 

SELECT *
FROM Students
ORDER BY age ASC;

For descending order: 

SELECT *
FROM Students
ORDER BY age DESC;

12. COUNT()

COUNT() counts records. 

SELECT COUNT(*)
FROM Students;

13. GROUP BY

GROUP BY groups records with similar values. 

SELECT course, COUNT(*)

FROM Students

GROUP BY course;

14. Primary Key

A primary key uniquely identifies each record in a table. 

CREATE TABLE Students (

    student_id INT PRIMARY KEY,

    name VARCHAR(100)

);

In this example, student_id is the primary key.

15. Foreign Key

A foreign key connects one table to another table. 

CREATE TABLE Courses (

    course_id INT PRIMARY KEY,

    course_name VARCHAR(100)

);


CREATE TABLE Students (

    student_id INT PRIMARY KEY,

    name VARCHAR(100),

    course_id INT,

    FOREIGN KEY (course_id)

    REFERENCES Courses(course_id)

);

16. JOIN

JOIN allows you to retrieve related information from multiple tables. 

SELECT
    Students.name,
    Courses.course_name

FROM Students

INNER JOIN Courses

ON Students.course_id = Courses.course_id;

17. LIKE

LIKE searches for a particular pattern. 

SELECT *

FROM Students

WHERE name LIKE 'K%';

The % means any number of characters.

18. BETWEEN 

SELECT *

FROM Students

WHERE age BETWEEN 20 AND 22;

19. DISTINCT

DISTINCT removes duplicate values from the result. 

SELECT DISTINCT course

FROM Students;

20. Complete Practical Example

Let's create a simple student database. 

CREATE DATABASE TechHubSchool;

USE TechHubSchool;


CREATE TABLE Students (

    student_id INT PRIMARY KEY,

    name VARCHAR(100),

    age INT,

    course VARCHAR(100),

    grade VARCHAR(5)

);


INSERT INTO Students

VALUES

(1, 'Kwame Mensah', 21,
'Information Technology', 'A'),

(2, 'Ama Boateng', 20,
'Computer Science', 'B'),

(3, 'Kofi Asante', 22,
'Cybersecurity', 'A');


SELECT * FROM Students;


SELECT name, course

FROM Students

WHERE grade = 'A';
